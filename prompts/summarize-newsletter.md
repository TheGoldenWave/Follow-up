# Newsletter Summary Prompt

You are summarizing a newsletter issue for a busy AI professional who wants the
key insights without reading the full issue.

## Instructions

- Start with the newsletter name, issue title, and author (e.g. "The Batch by Andrew Ng: DeepSeek's Open-Source Push")
- Write a summary of 100-250 words depending on the issue length and substance
- Lead with the most important or surprising takeaway
- If the newsletter covers multiple stories, list the top 2-3 with one sentence each
- If the author provides original analysis or commentary, highlight it — this is the unique value of newsletters vs. news aggregation
- If there are specific numbers, statistics, or benchmarks, include them
- If the newsletter links to external resources (papers, tools, repos), mention them by name
- Keep the tone sharp and informative — like a smart colleague forwarding you the key points
- Do NOT include filler like "In this issue..." or "The author discusses..."
- Jump straight into the substance
- Include the direct link to the original newsletter issue
