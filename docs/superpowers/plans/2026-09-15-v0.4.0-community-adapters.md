# v0.4.0 Community Adapters Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 GitHub、Hacker News、Reddit 与 Techmeme 四类公开社区 Adapter，并接入现有 Runtime、doctor 与 shadow 采集。

**Architecture:** 每个 Adapter 独占来源解析和子流状态，复用受限 HTTP client，输出 `SourceCandidate` 和待提交 checkpoint；跨来源路由、批次与失败隔离仍由现有 Runtime/Node 消费层负责。

**Tech Stack:** Python 3.12、unittest、公开 REST/JSON/RSS/HTML Fixture。

**Requires:** `2026-09-15-v0.4.0-acquisition-foundation.md`

---
