# v0.3.1 摘要校验交接修复计划

**目标：** 修复 validator 允许任意输出文件名而 finalize 要求 digestId 文件名的契约不一致，发布正式 v0.3.1 并升级首位用户本机。

**方案：** 保留 finalize 的文件名与 requestHash 防护，在 validator 写入前检查输出文件名；Skill 明确原始与验证后 manifest 使用不同目录、相同 digestId 文件名。Feed 过期仅披露，不扩大为采集系统改造。

**技术：** Node.js 原生测试、GitHub Release、现有 immutable installer。
