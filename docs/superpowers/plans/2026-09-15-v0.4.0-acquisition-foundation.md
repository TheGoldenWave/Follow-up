# v0.4.0 Acquisition Foundation Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 v0.4.0 六类新来源建立安全公共 HTTP、按子流增量 checkpoint、Registry 配置和原子状态提交基础。

**Architecture:** Adapter 保持只读解析职责，通过可注入 HTTP client 获取数据并在 `SourceResult.checkpoint_updates` 返回待提交状态。CLI 先验证并原子发布全部 Signal Batch，之后才以逐子流 CAS 提交来源状态。

**Tech Stack:** Python 3.12 标准库、unittest、现有 Signal Batch 1.0 Runtime。

**Canonical design:** `docs/superpowers/specs/2026-09-15-v0.4.0-community-academic-sources-design.md`
