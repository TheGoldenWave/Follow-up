# Follow-up v0.2.0 Product Closure Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish a verified `v0.2.0` Stable release that exposes the completed 17-source official Blog collector through an installable, configurable, and diagnosable Follow-up Skill.

**Architecture:** Keep the six centralized Feed envelopes as the runtime boundary for this release. Add channel filtering at Digest preparation, a small Node.js installer and doctor around the existing release manifest, and a compatibility-preserving Skill registration rename from `follow-builders` to `follow-up`; defer the Python Acquisition Runtime and local Adapters to `v0.3.0`.

**Tech Stack:** Node.js 20+, built-in `node:test`, JSON Schema, GitHub Releases, SHA-256 release verification.

**Canonical design:** `docs/superpowers/specs/2026-09-05-v0.2.0-product-closure-design.md`
