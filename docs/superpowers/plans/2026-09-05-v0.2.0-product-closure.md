# Follow-up v0.2.0 产品闭环开发计划

> **供 Agent 执行：** 必须使用 superpowers:subagent-driven-development（有子 Agent 时）或 superpowers:executing-plans 执行本计划。所有步骤使用 checkbox 跟踪；新增行为必须遵循 TDD，先观察失败再实现。

**目标：** 发布可验证安装的 v0.2.0 Stable 版本，将 17 个官网 Blog、六类中央 Feed、个性化重要性筛选、去重投递和诊断能力组合为可实际使用的 Follow-up 产品闭环。

**架构：** 保留六个 feed-*.json 作为 v0.1.0 兼容层，同时新增 feed-candidates.json 作为有界滚动候选池。中央采集负责稳定身份、来源状态、合并和留存；本地主机 Agent 负责语义评分并产出受 Schema 约束的选择清单；确定性代码负责渠道过滤、历史完整性、组合限制、投递台账和 outbox 状态机。安装器与 doctor 围绕已验证的 GitHub Release 工作，不在本版引入本地采集 Runtime、Sidecar 或自动回滚。

**技术栈：** Node.js 20+、ES Modules、内置 node:test、Ajv/JSON Schema、SHA-256、GitHub Actions/Releases。

**设计依据：** docs/superpowers/specs/2026-09-05-v0.2.0-product-closure-design.md
