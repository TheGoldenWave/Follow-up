# Follow-up v0.1.0 Baseline Release Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish a reproducible `v0.1.0` Stable baseline of Follow-up's current centralized six-Feed product without including planned or unsafe local Sidecar work.

**Architecture:** Treat the tagged repository as immutable product code and Prompts, while central Feeds remain mutable versioned data. Add one release manifest and validator as the version authority, test all version and Feed contracts, build archives from tracked files only, and publish the verified commit through an annotated Git tag and GitHub Release.

**Tech Stack:** Node.js 20+, built-in `node:test`, JSON, Git, GitHub CLI, SHA-256 release checksums.

**Canonical design:** `docs/superpowers/specs/2026-09-02-version-release-upgrade-design.md`
