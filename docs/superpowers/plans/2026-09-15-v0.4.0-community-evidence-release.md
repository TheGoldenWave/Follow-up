# v0.4.0 Community Evidence and Release Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把来源原生热度安全映射到 Candidate/Digest 1.1 契约，完成策展校验、消息渲染、真实 smoke、版本封装、正式发布和首位用户升级。

**Architecture:** Signal Batch 保持 1.0；Node 消费层按 adapter 白名单生成 HF 或通用社区 evidence。selection 与 artifact 一次升级到 1.1，完整候选并集贯穿 generation manifest、active state 和 delivery ledger。

**Tech Stack:** Node.js 20+、AJV Draft 2020-12、node:test、Python Adapter 输出、GitHub Release 工程。

**Requires:** 前三份 v0.4.0 实施计划。

- [x] **Step 6: 持久化合并**：同一 candidate 本次重新出现时，以本次映射结果为准；显式 dropped/无合法 evidence 会清除旧 evidence，避免陈旧热度。未在本次出现的历史 candidate 保留原 evidence 直至正常 retention；增加无该字段的历史 Candidate Feed 1.0 Fixture，证明向后兼容。
- [x] **Step 7: GREEN/回归**：shared evidence、candidate identity、normalization、Feed contract/store、prepare tests 通过。
