# v0.4.0 Academic Adapters Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现六个现有 arXiv 分类来源与 Hugging Face Papers 三视图来源，并稳定论文身份、日期语义和社区证据原始数据。

**Architecture:** arXiv 使用 RSS 发现与批量 Atom metadata 补齐；HF 使用公开结构化 Papers endpoint，按运行时区生成 Daily/Weekly 参数。两者均统一 `arxiv:<normalized-id>`，但保持独立候选供下游聚类。

**Tech Stack:** Python 3.12、feedparser 6.0.14、unittest、Atom/JSON Fixture、zoneinfo。

**Requires:** `2026-09-15-v0.4.0-acquisition-foundation.md`
